# Как добавлять контент без программиста

Уроки «Сахалыы саҥар» и якутские надписи интерфейса хранятся в **таблицах** в папке `content/`.
Перед каждой сборкой GitHub сам превращает таблицы в файлы приложения, поэтому достаточно
исправить таблицу и загрузить её обратно — через 5 минут в разделе Releases будет новый APK.

## Где таблицы

| Файл | Что в нём |
|---|---|
| `content/learning.csv` | Уроки «Сахалыы саҥар»: одна строка — одна карточка |
| `content/interface-sah.csv` | Надписи интерфейса: English, Русский и пустая колонка «Якутский» |

## Как поправить таблицу

1. На GitHub откройте папку `content`, нажмите на файл → кнопка **⋯** → **Download** (скачать).
2. Откройте файл в Excel, Numbers или Google Таблицах и внесите правки.
3. Сохраните как **CSV в кодировке UTF-8**, иначе пропадут якутские буквы ҥ, ҕ, ө, һ, ү:
   - Excel: «Файл → Сохранить как → CSV UTF-8 (разделитель — запятая)»;
   - Numbers: «Файл → Экспортировать → CSV → Кодировка: Юникод (UTF-8)»;
   - Google Таблицы: «Файл → Скачать → CSV».
4. На GitHub в папке `content` нажмите **Add file → Upload files**, перетащите файл
   (имя должно остаться прежним) → **Commit changes**.

## Уроки: колонки `learning.csv`

| Колонка | Что писать |
|---|---|
| `тема_id` | Короткое латинское имя темы, например `greetings`. Строки одной темы — подряд |
| `тема_ru`, `тема_en` | Название темы по-русски и по-английски |
| `подзаголовок_ru`, `подзаголовок_en` | Пояснение под названием темы (можно пусто) |
| `якутский` | Слово, фраза или буква по-якутски — **главное поле** |
| `перевод_ru`, `перевод_en` | Перевод |
| `подсказка_ru`, `подсказка_en` | Как произносить, примечание (можно пусто) |
| `аудио` | Имя файла озвучки — на будущее (можно пусто) |

Новая тема — просто строки с новым `тема_id`. Порядок тем и карточек в приложении — как в таблице.

## Якутский интерфейс: `interface-sah.csv`

Впишите перевод в колонку **«Якутский»**. Колонку «ключ» не трогайте. Где в тексте есть `%1$s`
или `%d` — оставьте их как есть: вместо них приложение подставит число.
Якутский язык включится в приложении, **когда будут заполнены все строки**. Выбрать его можно
на Android 13 и новее: Настройки → Приложения → Саҥарар кинигэ → Язык → Саха.
На телефонах на русском приложение по-русски, на остальных — по-английски.
