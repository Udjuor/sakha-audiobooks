# Саҥарар кинигэ

Android-приложение: якутская литература в исполнении актёров, с параллельным текстом
на якутском и русском.

**Стек:** Kotlin, Jetpack Compose, Material 3, Media3, Hilt, Room, Retrofit. minSdk 26, targetSdk 36.

## Как собрать APK

**В Android Studio:** File → Open → папка проекта → дождаться синхронизации →
кнопка ▶ Run (телефон подключён по USB с включённой «Отладкой по USB»).

**Из командной строки:** `./gradlew assembleDebug` → файл
`app/build/outputs/apk/debug/app-debug.apk`.

**Через GitHub:** готовые APK лежат в разделе Releases. Новый релиз: добавить файл
`release-notes/<версия>.md` (первая строка — заголовок) и отправить в main.

## Книги в приложении

Пока сервера нет, каталог встроен в приложение: `app/src/main/assets/demo/catalog.json`
(позже тот же формат будет отдавать сервер). Сейчас там три якутские народные сказки:
«Биэс ынахтаах Бэйбэрикээн эмээхсин», «Куобах» и «Куобах уонна баҕа» — якутский текст
и обложки в `covers/`; у «Куобах уонна баҕа» есть аудиозапись (`kuobakh_baga.m4a`).
Подходят файлы mp3 и m4a.

Учебные карточки раздела «Сахалыы саҥар» — в `assets/demo/learning.json`.

**Добавить аудиозапись:** положить mp3 или m4a в `app/src/main/assets/demo/` и в `catalog.json`
у главы указать `"audio": "имя-файла.mp3"` и `"duration_sec"` — длительность в секундах.
Пока `audio` пустое, плеер у книги скрыт.

## Плеер

Звук играет в фоновой службе `player/PlaybackService` (Media3): не прерывается при выключенном
экране и на других вкладках, управляется из шторки, с экрана блокировки и кнопками гарнитуры.
Экраны управляют им через `player/PlayerConnection`.

## Структура

```
app/src/main/java/ru/sakhabooks/app/
  ui/theme       — цвета, шрифты (тёплая палитра)
  ui/components  — общие элементы, в т.ч. OrnamentBand (место под орнамент)
  ui/navigation  — адреса экранов и нижнее меню
  ui/<экран>     — экраны приложения (catalog, book — плеер и текст, player — мини-плеер)
  player         — фоновая служба плеера и «пульт» для экранов
  data           — каталог книг, место остановки и скорость
app/src/main/res/values/strings.xml — все надписи интерфейса
```

## Перевод интерфейса на якутский

Скопировать `res/values/strings.xml` в `res/values-sah/strings.xml`, перевести значения,
добавить `<locale android:name="sah" />` в `res/xml/locales_config.xml`.
