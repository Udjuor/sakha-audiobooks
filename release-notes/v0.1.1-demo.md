# Демо-версия 0.1.1 — «Колобок»
Исправлена установка: теперь все тестовые сборки подписаны одним постоянным ключом.

**Важно, один раз:** если на телефоне уже стоит «Саҥарар кинигэ» из прошлых сборок, сначала удалите его, затем установите этот файл. Дальше новые версии будут ставиться поверх как обновление.

**Что внутри**
- Сказка «Колобок» на якутском: аудио, якутский текст и русский перевод. Работает без интернета.
- Каталог с карточками книг.
- Плеер: пауза, перемотка ±15 секунд, скорость 0,75–2×, запоминание места остановки.
- Текст: саха / русский / оба сразу.

**Как установить:** скачайте `sanarar-kinige-v0.1.1-demo.apk` ниже, откройте на телефоне и разрешите установку из этого источника.
