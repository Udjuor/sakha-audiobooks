# Демо-версия 0.1 — «Колобок»
Первая демо-версия приложения «Саҥарар кинигэ».

**Что внутри**
- Сказка «Колобок» на якутском: аудио, якутский текст и русский перевод. Работает без интернета.
- Каталог с карточками книг.
- Плеер: пауза, перемотка ±15 секунд, скорость 0,75–2×, запоминание места остановки.
- Текст: саха / русский / оба сразу.

**Как установить:** скачайте файл `sanarar-kinige-v0.1-demo.apk` ниже, откройте его на телефоне и разрешите установку из этого источника.

Это тестовая сборка: якутский текст и перевод ещё проверяет переводчик.
